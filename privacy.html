Quilta Capture 隐私说明

Quilta Capture 是配套 Quilta Mac 应用的 Chrome 收藏扩展，供你将主动选择的网页素材收藏到本机灵感资料库。

何时及如何处理页面内容

扩展在你主动点击工具栏图标并选择捕获内容时处理当前页面。内容包括所选区域或整页的截图、可取得的文字、结构、样式、布局及来源信息；来源包含页面完整网址，可能包含查询参数或片段。你也可以明确开始录制静音视频，预览后选择收藏或取消。

捕获的网页或视频可能包含页面上显示的个人信息。扩展不自动识别或过滤这些信息，请在收藏前核对所选内容。

扩展不读取Chrome浏览历史列表或Cookies，不后台记录你访问的全部网页，不使用摄像头或麦克风。动效只采集当前标签页的视频，不录制声音；相关可选权限在你主动录制时申请。

本机处理和保存

选区、录制与预览在本机处理。明确收藏后，内容通过 Chrome Native Messaging 交给同一台 Mac 上的 Quilta。传输使用本机临时文件，导入完成或失败后清理；成功收藏的素材保存在Quilta本机资料库。移除扩展不会删除已经收藏的素材，可在Quilta中管理这些内容。

扩展不把收藏内容上传到开发者服务器，不包含广告、分析或遥测服务，不出售用户数据，不执行远程提供的扩展代码。扩展安装、审核和更新由Chrome Web Store按其平台规则提供。

用户数据的有限用途

Quilta Capture 对用户数据的处理遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。扩展取得的页面内容与来源只用于你主动选择的收藏功能及其必要本机传送，不用于广告、用户画像或与该功能无关的用途，不出售或为这些目的传输数据。

扩展不会自动将收藏内容提供给开发者，也不允许开发者人员通过扩展读取这些内容。若你联系支持，仅在你明确同意为解决问题查看具体提交材料时处理你选择发送的说明或脱敏截图；请勿发送许可证、资料库、钥匙串或私人网页内容。配套App激活及你另行配置的Codex参考，遵循下文的独立流程和服务说明。

配套App及可选服务

本扩展需要兼容的Quilta Mac应用和相应使用许可才能保存素材。配套App首次激活需要联网，该流程使用许可和随机本机标识验证使用权并记录设备名额，不属于扩展上传网页内容的流程；详情以App中的许可说明为准。

Quilta可以在你另行授权后将选定素材设为Codex只读参考。Codex读取和模型服务的数据处理遵循你的Codex配置及对应服务规则。本扩展本身不会自动将收藏发送给Codex或模型提供商。
